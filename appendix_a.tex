В приложении приведены результаты экспериментов на бенчмарках JOB (113 запросов) и JOB-Complex (30 запросов) при стандартных оценках кардинальностей PostgreSQL. Для базового алгоритма DPsize (\texttt{standard\_join\_search}) приведены абсолютные значения времени планирования \texttt{plan} (в~мс), времени исполнения \texttt{exec} (в~мс), их суммы \texttt{total} (в~мс) и оценочной стоимости плана \texttt{cost} (без единиц измерения, шкала PostgreSQL). Для остальных подходов значения нормированы на соответствующие значения DPsize: значение меньше единицы означает выигрыш относительно DPsize, больше единицы~--- проигрыш.

Условные обозначения подходов: $\mathrm{GOO_{cost}}$~--- жадный алгоритм по стоимости; $\mathrm{GOO_{card}}$~--- жадный по кардинальности; $\mathrm{GOO_{cc}}$~--- жадный по комбинации стоимости и кардинальности; \enquote{Top.~Iter.~Dec.}~--- топологическая итеративная декомпозиция; DPhyp$_{\mathrm{mod}}$~--- модифицированный DPhyp.
